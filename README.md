# Projeto da Materia de Autoria Web 
### Projeto de Cópia da Página do G1
**Descrição:**
Este projeto foi desenvolvido como atividade do 1º bimestre, com o objetivo de estudar e praticar **HTML** e **CSS**. A tarefa consistiu em recriar a página do G1, replicando sua estrutura e estilo para entender melhor a construção de layouts e a estilização de elementos de uma página real. A atividade permitiu o desenvolvimento das habilidades de marcação e estilização, além de uma compreensão mais prática dos conceitos de front-end.
